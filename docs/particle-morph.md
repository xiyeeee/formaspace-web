# 登录页点云形态变换

登录页背景现在使用同一批 10,500 个 GPU 粒子，按以下顺序循环：

**龙卷风 → 荷花绽放 → 河流 → 蝴蝶群 → 龙卷风**

- 龙卷风：五条主要螺旋流带，粒子从下向上旋转，漏斗上宽下窄。
- 荷花：四层花瓣从包拢的花苞逐层向外舒展，形成向上托起的花冠，配花蕊、茎和带缺口的荷叶。
- 河流：粒子沿 S 形河道移动，加入细小水波与局部反光。
- 蝴蝶群：五只大小、飞行高度与深度不同的蝴蝶，从左向右错落飞过，分别拥有扇翅频率、相位、倾斜与起伏。共用 10,500 粒子，每只分配约 2,100 点，不增加绘制对象。

龙卷风、河流分别展示 5.5 秒，荷花展示 8.5 秒，蝴蝶群展示 7.5 秒，每次转换 3 秒，名义循环时长 39 秒。荷花先保持含苞，外层先开、内层延迟，充分展开后短暂停留。时间推进在页面隐藏时暂停，恢复时限制时间步；低帧率设备可能略慢。过渡采用带少量错峰的 smoothstep 与弧线位移；过渡期间暂停各形态自身的循环流动，避免龙卷风 / 河流的粒子回流重置在半透明混合中产生跳点。花瓣展开独立跟随形态年龄。

形态由参数曲面程序生成，不依赖外部模型或网络资源。所有位置、固有运动与过渡在 Shader 内计算，没有为单个粒子创建 React 组件，也不逐帧更新 React 状态。

粒子较上一轮减少约 60%，尺寸和透明度保留变化。花瓣边缘、蝶翼轮廓和脉络相对清晰，内部较轻薄；标题和表单区域在屏幕空间渐隐。保留已有全屏 Canvas，河流横跨画面；龙卷风、花朵和蝴蝶保持可辨的整体轮廓。流体拖尾强度降至 0.3，作为辅助。

加载占位、移动端和 WebGL 不可用时均使用龙卷风初始点云，与动画首帧共用粒子种子、相机投影和布局。首个 WebGL 帧绘制完成后才移除占位，避免刷新时先出现蝴蝶再切换。减少动效时停止形态切换和自身运动。原有错误边界、上下文丢失回退、监听器清理和 GPU 资源释放机制保留。账号表单、接口与鉴权流程没有改动。

## 文件

- `src/features/auth/lib/particle-morph.ts`：循环时间、粒子种子、静态降级。
- `src/features/auth/lib/particle-forms/`：四种独立形态模块，各自保存采样、运动、展示时长和镜头；`index.ts` 为统一注册入口。
- `src/features/auth/lib/shaders/particle-forms.ts`：组装 Shader 片段，并从注册表生成形态分发。
- `src/features/auth/lib/shaders/particle-morph.ts`：连续变换、鼠标扰动、粒子显示。
- `src/features/auth/components/particle-scene.tsx`：复用现有 R3F 场景和渲染循环。
- `src/features/auth/components/auth-visual.tsx`、`auth.css`：静态回退与背景样式。

## 随形态变化的镜头

四种形态各有镜头轨道：龙卷风从原始正面缓缓转到略低侧视；花朵采用斜俯视；河流采用沿水道的斜向低位观察；蝴蝶采用接近飞行高度的侧面平视。展示阶段只做轻微移动，形态切换阶段用五阶缓动与小幅上拱路径切换镜头位置、观察目标和景别，不做无休止环绕。

`src/features/auth/lib/particle-camera.ts` 负责镜头过渡与构图，镜头参数由各形态模块分别维护。通过投影偏移保持主体中心位于原构图位置，表单仍为固定 HTML。粒子布局始终以初始相机的参考视口计算，窗口变化不会因当前镜头角度而反复改变主体尺寸。

花瓣增加弯曲和层间深度，河流改为真实 XZ 水面与横向河岸方向，蝶翼补充弯曲和身体厚度。首个龙卷风镜头仍从原始相机姿态出发，与加载占位一致；减少动效时镜头同样静止。

本地 Chromium 简短查看了四种视角与切换，控制台无错误，表单仍可输入。截图已更新；未进行接口回归或额外性能压测。

荷花镜头从花苞的侧面渐渐抬升，展示完整的花冠层次；蝴蝶群使用更宽的镜头容纳飞行路径。刷新首屏仍为原始龙卷风，没有改变加载占位。新增含苞 / 开放中截图 `morph-lotus-bud.png`、`morph-lotus-opening.png`。

蝴蝶群已改为蝶身朝向飞行路径、双翼水平展开并上下扇动，随路径切线调整俯仰与朝向。镜头降至接近飞行高度，以人眼平视的侧向角度观察左到右飞行；加大双翼上下扇动幅度，让平视时仍可辨认翼面，避免正对蝶腹、蝶身竖直横移的贴片观感。

## 扩展结构

四种形态已拆为 `particle-forms/{tornado,lotus,river,butterfly}.ts`。新增形态只需实现同一契约并注册；展示时长、阶段数、镜头与 GPU 分发索引随注册表生成。扩展方法见 [形态模块说明](../src/features/auth/lib/particle-forms/README.md)。本次仅调整结构，保留现有计算、播放顺序、镜头数值和单 Points 渲染方式。
