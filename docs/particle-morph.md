# 登录页点云形态变换

登录页背景现在使用同一批 10,500 个 GPU 粒子，按以下顺序循环：

**龙卷风 → 水母群 → 河流与小船 → 宇航员挥手 → 龙卷风**

- 龙卷风：五条主要螺旋流带，粒子从下向上旋转，漏斗上宽下窄。
- 水母群：六只大小、深度和收缩节奏不同的水母，错落漂浮；伞盖收缩时微微上浮，触须延迟摆动，保留浅蓝与淡紫的透明感。
- 河流与小船：粒子沿 S 形河道流动，三只点云帆船顺河道前进，船体跟随水面高度、轻微俯仰和侧倾，带少量船尾水纹。
- 宇航员挥手：圆形头盔、金色面罩、厚宇航服、背包、胸前控制面板与手套；右臂抬起挥手，双腿放松漂动，身体有轻微失重起伏。共用 10,500 粒子，少量粒子分配给暗淡星点。

龙卷风、河流分别展示 5.5 秒，水母群展示 8.5 秒，宇航员展示 7.5 秒，每次转换 3 秒，名义循环时长 39 秒。水母群在固定散点位置附近轻微游动，不会逐帧随机换位置。时间推进在页面隐藏时暂停，恢复时限制时间步；低帧率设备可能略慢。过渡采用带少量错峰的 smoothstep 与弧线位移；过渡期间暂停各形态自身的循环流动，避免龙卷风 / 河流的粒子回流重置在半透明混合中产生跳点。水母伞盖、触须与自身上浮使用错开的周期，切换时继续平滑变形。

形态由参数曲面程序生成，不依赖外部模型或网络资源。所有位置、固有运动与过渡在 Shader 内计算，没有为单个粒子创建 React 组件，也不逐帧更新 React 状态。

粒子较上一轮减少约 60%，尺寸和透明度保留变化。水母伞缘、船帆与宇航员轮廓相对清晰，内部较轻薄；标题和表单区域在屏幕空间渐隐。保留已有全屏 Canvas，河流横跨画面；龙卷风、水母和宇航员保持可辨的整体轮廓。流体拖尾强度降至 0.3，作为辅助。

加载占位、移动端和 WebGL 不可用时均使用龙卷风初始点云，与动画首帧共用粒子种子、相机投影和布局。首个 WebGL 帧绘制完成后才移除占位，避免刷新时先出现蝴蝶再切换。减少动效时停止形态切换和自身运动。原有错误边界、上下文丢失回退、监听器清理和 GPU 资源释放机制保留。账号表单、接口与鉴权流程没有改动。

## 文件

- `src/features/auth/lib/particle-morph.ts`：循环时间、粒子种子、静态降级。
- `src/features/auth/lib/particle-forms/`：四种独立形态模块，各自保存采样、运动、展示时长和镜头；`index.ts` 为统一注册入口。
- `src/features/auth/lib/shaders/particle-forms.ts`：组装 Shader 片段，并从注册表生成形态分发。
- `src/features/auth/lib/shaders/particle-morph.ts`：连续变换、鼠标扰动、粒子显示。
- `src/features/auth/components/particle-scene.tsx`：复用现有 R3F 场景和渲染循环。
- `src/features/auth/components/auth-visual.tsx`、`auth.css`：静态回退与背景样式。

## 随形态变化的镜头

四种形态各有镜头轨道：龙卷风从原始正面缓缓转到略低侧视；水母采用宽一些的斜正面视角；河流采用斜俯视以看清船体和船帆；宇航员采用斜正面视角以看清面罩与挥手。展示阶段只做轻微移动，形态切换阶段用五阶缓动与小幅上拱路径切换镜头位置、观察目标和景别，不做无休止环绕。

`src/features/auth/lib/particle-camera.ts` 负责镜头过渡与构图，镜头参数由各形态模块分别维护。通过投影偏移保持主体中心位于原构图位置，表单仍为固定 HTML。粒子布局始终以初始相机的参考视口计算，窗口变化不会因当前镜头角度而反复改变主体尺寸。

水母的伞盖和触须均在三维空间采样，河流沿真实 XZ 水面分布，宇航员通过厚宇航服与关节姿态表现漂浮。首个龙卷风镜头仍从原始相机姿态出发，与加载占位一致；减少动效时镜头同样静止。

本地 Chromium 简短查看了四种视角与切换，控制台无错误，表单仍可输入。截图已更新；未进行接口回归或额外性能压测。



## 扩展结构

四种形态已拆为 `particle-forms/{tornado,jellyfish,river,astronaut}.ts`。新增形态只需实现同一契约并注册；展示时长、阶段数、镜头与 GPU 分发索引随注册表生成。扩展方法见 [形态模块说明](../src/features/auth/lib/particle-forms/README.md)。本次仅调整结构，保留现有计算、播放顺序、镜头数值和单 Points 渲染方式。

## 水母群与河流小船

`jellyfish.ts` 替换荷花注册项，`lotus.ts` 保留为备用。每只水母使用固定种子区分大小、色调和收缩频率，锚点错落分布，周围叠加小幅连续漂动。穹顶状伞盖、伞缘和十条触须分开采样，保持同一批粒子的连续切换。

河流继续使用单一形态模块，约 76% 粒子分配给水面、24% 分配给三只帆船；船体、船舷、桅杆、双帆和尾流分别采样。船沿河道切线定向，使用同一河道位置与水面波函数确定船体位置。河道两端淡入淡出，形态过渡期间冻结循环流动，避免回流重置时跳位。

粒子总数、绘制对象和依赖均未增加。已完成 lint / build，以及本地 Chromium 的水母收缩、帆船与表单输入简短检查，无控制台错误。截图为 `morph-jellyfish.png`、`morph-jellyfish-pulse.png`、`morph-river-boats.png`；旧荷花截图仅为历史参考。

船体与船帆已相对水面抬高 0.1 局部单位，尾流维持原水面高度；船身覆盖范围内的水面粒子柔和减淡，避免加法混合使船、水轮廓粘连。镜头角度不变。
