# 维境 VISION 3D · 设计稿整理

版本：2026-11-16

## 推荐使用
1. 创作工作台-完成态：左侧上传和参数，中央模型画布，右侧资产与属性。
2. 创作工作台-点云生成态：沿用同一布局，中央使用点云与扫描动画呈现等待过程。
3. 登录页-沉浸点云版：全屏抽象点云雕塑，右侧悬浮表单，为当前推荐登录方向。

## 早期方案参考
保留陶瓷狐狸登录页、早期四屏概念，供比较；不作为新版开发的主要依据。

## 视觉与交互说明
- 石墨灰背景、暖白文字、黄绿色强调；保持面板简洁，让中央画布成为主角。
- 登录背景：缓慢运动；鼠标附近粒子轻微散开，离开后回归；可叠加轻微空间视差。
- 表单保持稳定，表单区域不触发背景粒子交互；低性能设备及减少动态效果偏好下简化动画。
- 工作台生成中：保留原图，禁用重复提交；完成后切换实体模型预览。
- 若生成接口不提供中间三维数据，等待时只能展示图片粒子化或通用点云动画；获得模型后才能展示对应真实三维点云。不得把概念动画作为实际生成进度。

## 开发前需确认
- 图片均为静态概念设计稿，不含可编辑 Figma 源文件、网页代码或 GLB 模型。
- 品牌名与标志暂定；各图标志略有变化，落地时需统一。
- 积分、额度、文件大小、耗时及格式均为视觉占位。生成页中“预计10–30秒”应删除，按真实接口确定。
- 单图/多图、质量档位、贴图、验证码登录、下载格式等需与实际后端能力对齐。
- 生成进度没有真实数据时使用不定进度提示，不展示虚构百分比。
- 尚需补充：未上传、已上传待生成、生成失败、注册/找回密码及移动端布局。
